## Limits

* Real RPC account proof at supplied block 25949241; canonicality/finality is not independently established. No independent header verification lane exists in inspected source.
* Account path, root and balance scope only; storage, receipts/transaction roots and full deployment semantics are excluded.
* Original source functions execute on pinned JavaScript dependencies; expectation uses separate Python Keccak/RLP/MPT obligations. No shared semantic helper or adapter/predictor call dependency. Author independence and exhaustive cryptographic assurance are not established.
* Existing ASCII transport faithfully carries hex proof bytes/quantities and exact wei decimal strings. Upstream float ETH display is explicitly outside this partial semantic projection. No silent numeric/Unicode coercion.
* No external repository changed. No other domain started. No public publication, PR, tag or release.
